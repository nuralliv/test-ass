# Тестовое задание: backend-разработчик (Node.js / TypeScript)

Две небольшие задачи на уже начатом коде. Нам важно увидеть, как вы разбираетесь в чужом проекте, дописываете его и что считаете готовым результатом.

- [Задача 1. Распределение заказов по филиалам](task-1-dispatch/README.md)
- [Задача 2. Онлайн-запись к мастеру](task-2-booking/README.md)

Ориентир — 4–6 часов на обе. Если не успеваете всё, лучше доведите до конца часть пунктов и напишите в `NOTES.md`, что осталось и как бы вы это сделали.

## Запуск

Нужен Node.js 22.18 или новее: TypeScript запускается напрямую, без сборки.

```bash
npm install          # ставится только typescript и типы для проверки
npm test
npm run typecheck
npm run start:dispatch   # http://localhost:3001
npm run start:booking    # http://localhost:3002
```

## Правила

- Существующий код можно менять как угодно, включая сигнатуры функций и тесты под них.
- Хранилище остаётся в памяти, базу данных подключать не нужно.
- Зависимости добавлять можно, если сможете объяснить, зачем они.
- Тесты — на `node:test`, примеры уже есть.
- Не меняйте переменные окружения `PORT`, `DATA_DIR`, `NOW`: по ним мы запускаем свои проверки.
- Коммитьте по ходу работы, а не одним коммитом в конце.

## Как сдать

1. Сделайте форк репозитория и решайте задачи в нём.
2. В корне положите `NOTES.md`: что сделано, какие допущения приняли, что бы доделали.
3. Прикрепите ссылку на форк с решением к отклику на вакансию. Отклики без ссылки на решение не рассматриваем.

Решение должно быть вашим: после проверки будет созвон на 30–40 минут, на нём попросим объяснить решение и поменять в нём что-нибудь вживую.
